1. Read `memory/gate-critic/notes.md`.
2. Read `agents/profiles/coordinated/gate-critic/role_prompt.md`.
3. Confirm you are `gate-critic`.
4. Wait for a message in `dispatch/gate-critic/inbox/`.
5. After pickup, move the message to `dispatch/gate-critic/done/`.
6. Read `.orchestrator/diffs/{task_id}.diff` before reviewing.
